parser.go — Reading Raw HTTP

The parser is the most complex component. It takes a raw TCP connection and turns the byte stream into a structured request your handlers can act on. Module 2 was the theory — this is the implementation.

The Request type

package server type Request struct { Method string Path string Headers map[string]string Body []byte }

The full parser

const ( maxHeaderCount = 50 maxBodySize = 1 << 20 // 1MB readTimeout = 30 * time.Second ) func ParseRequest(reader *bufio.Reader, conn net.Conn) (*Request, error) { conn.SetReadDeadline(time.Now().Add(readTimeout)) // ── Request line ── line, err := reader.ReadString('\n') if err != nil { return nil, err } line = strings.TrimRight(line, "\r\n") parts := strings.SplitN(line, " ", 3) if len(parts) != 3 || parts[2] != "HTTP/1.1" { return nil, ErrBadRequest } req := &Request{ Method: parts[0], Path: parts[1], Headers: make(map[string]string), } // ── Headers ── for count := 0; count < maxHeaderCount; count++ { line, err = reader.ReadString('\n') if err != nil { return nil, err } line = strings.TrimRight(line, "\r\n") if line == "" { break // blank line = end of headers } idx := strings.IndexByte(line, ':') if idx < 1 { return nil, ErrBadRequest } k := strings.ToLower(strings.TrimSpace(line[:idx])) v := strings.TrimSpace(line[idx+1:]) req.Headers[k] = v } // ── Body ── clStr := req.Headers["content-length"] if clStr != "" { n, err := strconv.Atoi(clStr) if err != nil || n < 0 || n > maxBodySize { return nil, ErrBadRequest } req.Body = make([]byte, n) if _, err = io.ReadFull(reader, req.Body); err != nil { return nil, err } } return req, nil }
ErrBadRequest is a sentinel value
Define var ErrBadRequest = errors.New("bad request") in the package. When the caller (handleConn) receives this error from ParseRequest, it writes a 400 response. Other errors — io.EOF, timeout errors — signal different conditions: connection closed, deadline exceeded. The caller checks errors.Is(err, ErrBadRequest) to distinguish.

The keep-alive loop in handleConn

func handleConn(conn net.Conn, router *Router) { defer conn.Close() reader := bufio.NewReader(conn) for { req, err := ParseRequest(reader, conn) if err != nil { if errors.Is(err, ErrBadRequest) { WriteError(conn, 400) } return // EOF, timeout, or unrecoverable } resp := router.Handle(req) WriteResponse(conn, resp) if strings.ToLower(req.Headers["connection"]) == "close" { return } } }
