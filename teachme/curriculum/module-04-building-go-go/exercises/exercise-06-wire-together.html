Wire It All Together

You have all the components. Now build cmd/server/main.go, wire them together, run the server, and hit it with real requests.

main.go

The entry point is simple — it just parses flags and calls server.Run:

package main import ( "flag" "github.com/yourname/go-go/cache" "github.com/yourname/go-go/server" ) func main() { port := flag.String("port", "8080", "port to listen on") workers := flag.Int("workers", 10, "number of worker goroutines") flag.Parse() store := cache.New() server.Run(*port, *workers, store) }

The smoke tests

Run the server in one terminal, then run these commands in another. Each one tests a specific behavior.

Test 1
Set a value
curl -s -X PUT localhost:8080/keys/greeting -d '"hello"' -H "Content-Type: application/json"
Expected: {"ok":true}
Test 2
Get the value back
curl -s localhost:8080/keys/greeting
Expected: "hello" — the exact bytes you stored
Test 3
List all keys
curl -s localhost:8080/keys
Expected: ["greeting"]
Test 4
Get a missing key
curl -s -o /dev/null -w "%{http_code}" localhost:8080/keys/missing
Expected: 404
Test 5
Invalid JSON body
curl -s -o /dev/null -w "%{http_code}" -X PUT localhost:8080/keys/bad -d 'notjson'
Expected: 400
Test 6
Delete a key
curl -s -X DELETE localhost:8080/keys/greeting && curl -s -o /dev/null -w "%{http_code}" localhost:8080/keys/greeting
Expected: {"ok":true} then 404
Test 7
Race detector — concurrent load
go run -race ./cmd/server/main.go & for i in {1..50}; do curl -s -X PUT localhost:8080/keys/k$i -d '"v"' & curl -s localhost:8080/keys/k$i & done; wait
No race condition output from the server. Kill the server with Ctrl-C — should exit cleanly.

Full test suite

Verification checklist

You shipped it
A working HTTP/1.1 server from raw TCP sockets, written entirely in Go stdlib. No net/http, no frameworks, no dependencies. You understand every byte that enters and leaves the process. That's the goal — not just a working server, but a server you can explain at any level of the stack.
