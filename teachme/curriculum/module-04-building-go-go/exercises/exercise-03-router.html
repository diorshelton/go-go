Implement router.go

Four routes, one switch statement, and four handlers. The router is where request dispatch meets the cache.

The routes

MethodPathHandlerResponse
GET/keyshandleGetAll200, JSON array of keys
GET/keys/:idhandleGet200 value | 404
PUT/keys/:idhandlePut200 | 400 invalid JSON
DELETE/keys/:idhandleDelete200

The Router type

type Router struct { store *cache.Store } func NewRouter(store *cache.Store) *Router { return &Router{store: store} }

Implement Handle

Use a switch with compound cases — method AND path together. Extract the :id segment using strings.TrimPrefix(path, "/keys/"). If the prefix was present but the result is empty (i.e., the path was exactly /keys/), return 404.

GET /keys vs GET /keys/:id
Order matters. Check path == "/keys" before strings.HasPrefix(path, "/keys/"). If you check HasPrefix first, /keys won't match it (no trailing slash), but it's still a potential ambiguity to be aware of. Explicit equality for the collection route, prefix for the individual route.

Implement the handlers

handleGetAll: call store.Keys(), marshal the result to JSON (use encoding/json), return 200.

handleGet: call store.Get(id). If ok is false, return 404 with {"error":"not found"}. If true, return 200 with the raw value (it's already JSON bytes — no re-encoding needed).

handlePut: call json.Valid(req.Body). If false, return 400 with {"error":"invalid json"}. If true, call store.Set(id, json.RawMessage(req.Body)), return 200 with {"ok":true}.

handleDelete: call store.Delete(id), return 200 with {"ok":true}.

Write a table test

func TestRouter(t *testing.T) { s := cache.New() r := server.NewRouter(s) cases := []struct { method, path, body string wantStatus int }{ {"GET", "/keys", "", 200}, {"GET", "/keys/missing", "", 404}, {"PUT", "/keys/foo", `"bar"`, 200}, {"PUT", "/keys/bad", "notjson", 400}, {"GET", "/keys/foo", "", 200}, {"DELETE", "/keys/foo", "", 200}, {"GET", "/keys/foo", "", 404}, } for _, tc := range cases { req := &server.Request{Method: tc.method, Path: tc.path, Body: []byte(tc.body)} resp := r.Handle(req) if resp.Status != tc.wantStatus { t.Errorf("%s %s: got %d, want %d", tc.method, tc.path, resp.Status, tc.wantStatus) } } }
