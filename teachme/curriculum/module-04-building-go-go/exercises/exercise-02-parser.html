Implement parser.go

The parser is the hardest component. You're turning raw bytes into a structured request — with defensive validation at every step.

What you're building

Create server/parser.go with the Request struct, the ErrBadRequest sentinel, and the ParseRequest function. Also implement handleConn in the same file or a companion file.

Start with the types

var ErrBadRequest = errors.New("bad request") const ( maxHeaderCount = 50 maxBodySize = 1 << 20 // 1 MiB readTimeout = 30 * time.Second ) type Request struct { Method string Path string Headers map[string]string Body []byte }

Implement ParseRequest in stages

Stage 1 — Read deadline
Set the deadline before any read
conn.SetReadDeadline(time.Now().Add(readTimeout)) — this covers the entire request read. If parsing takes longer than 30 seconds (slow client, slow network), the deadline fires and ReadString returns a timeout error.
Stage 2 — Request line
Read and parse the first line
reader.ReadString('\n'), then strings.TrimRight(line, "\r\n"), then strings.SplitN(line, " ", 3). Validate: exactly 3 parts, third part is "HTTP/1.1". Any failure → return nil, ErrBadRequest.
Stage 3 — Headers
Loop until blank line
Loop up to maxHeaderCount times. Each iteration: read a line, trim CRLF. If the trimmed line is empty, break. Otherwise: find the colon with strings.IndexByte(line, ':'), lowercase the key with strings.ToLower, trim space from both key and value.
Stage 4 — Body
Read exactly Content-Length bytes
Check req.Headers["content-length"]. If present: parse with strconv.Atoi, validate n >= 0 && n <= maxBodySize. Allocate make([]byte, n). Call io.ReadFull(reader, req.Body). If n is 0 or no Content-Length header, skip body.
The trap: reading past Content-Length
Never read more than Content-Length bytes from the body. On a keep-alive connection, the bytes immediately after the body are the next request's request line. If you over-read, the next ParseRequest call will see garbage and return ErrBadRequest. io.ReadFull(reader, req.Body) reads exactly len(req.Body) bytes — no more, no less.

Write a test

func TestParseRequest(t *testing.T) { raw := "PUT /keys/foo HTTP/1.1\r\nContent-Length: 5\r\n\r\nhello" reader := bufio.NewReader(strings.NewReader(raw)) req, err := ParseRequest(reader, &fakeConn{}) if err != nil { t.Fatal(err) } if req.Method != "PUT" { t.Errorf("got method %s", req.Method) } if string(req.Body) != "hello" { t.Errorf("got body %s", req.Body) } }
fakeConn for testing
ParseRequest takes a net.Conn to call SetReadDeadline. In tests, you can't use a real connection. Create a fakeConn struct that implements net.Conn with no-op methods. For SetReadDeadline, just return nil. The actual reading happens through the bufio.Reader you pass in, not through the conn.
