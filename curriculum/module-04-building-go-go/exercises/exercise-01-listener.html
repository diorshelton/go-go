Implement listener.go

Build the TCP accept loop and graceful shutdown from scratch. This is the outermost layer — everything else plugs into it.

What you're building

Create server/listener.go with a single exported function Run(port string, workers int, store *cache.Store). It should:

  1. Open a TCP listener on the given port
  2. Start the worker pool
  3. Handle OS signals for graceful shutdown
  4. Accept connections in a tight loop and submit them to the pool
  5. Call pool.Shutdown() after the loop exits

Step by step

Step 1
Open the listener
Call net.Listen("tcp", ":"+port). If it fails, call log.Fatalf — a listener failure is unrecoverable. Store the result in ln.
Step 2
Create the router and pool
Call NewRouter(store) to get a router, then pool.New(workers, router) to get the pool. The pool takes the router so workers know how to handle connections.
Step 3
Wire up the signal handler
Create a buffered channel: quit := make(chan os.Signal, 1). Call signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM). Launch a goroutine that blocks on <-quit, then calls ln.Close(). The goroutine will block until a signal arrives — only then will it close the listener and cause Accept() to return an error.
Step 4
The accept loop
for { conn, err := ln.Accept(); if err != nil { break }; pool.Submit(conn) }. That's it. Any error from Accept breaks the loop — including the error from ln.Close() on shutdown.
Step 5
Drain and exit
After the loop: pool.Shutdown(). This closes the connection channel and waits for all workers to finish their current connections via WaitGroup.

Verification checklist

Common mistake
Forgetting the goroutine around the signal handler and putting <-quit directly in the main goroutine — then your accept loop never runs because the main goroutine is blocked waiting for a signal. Always: signal handler in a goroutine, accept loop in the calling goroutine.
