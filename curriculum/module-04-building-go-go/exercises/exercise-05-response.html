Implement response.go

The smallest component. Its correctness is visible to every client that talks to your server.

What you're producing on the wire

HTTP/1.1 200 OK\r\n Content-Type: application/json\r\n Content-Length: 15\r\n Connection: keep-alive\r\n \r\n {"key":"value"}

What to implement

Create server/response.go. You need three things:

  1. WriteResponse(conn net.Conn, resp *Response, keepAlive bool) — formats the status line, headers, blank line, and body. Writes header as a single formatted string, then body bytes separately.
  2. WriteError(conn net.Conn, status int) — builds a JSON error body ({"error":"Bad Request"}) and calls WriteResponse with keepAlive: false.
  3. statusText(code int) string — unexported helper that maps status codes to reason phrases. Cover 200, 400, 404, 405, 413 at minimum.
The variable shadowing trap from the lesson
If you write conn := "close" inside a function that takes conn net.Conn, the new conn shadows the parameter. Your subsequent conn.Write(...) calls will fail to compile. Use a distinct name for the Connection header value: connHeader := "close".

Verify with curl

Once the full server is wired (next exercise), test the response format directly:

# Set a value curl -v -X PUT localhost:8080/keys/msg -d '"hello"' # Look at the response headers in the verbose output # You should see: Content-Type, Content-Length, Connection # Verify Content-Length matches the actual body curl -s localhost:8080/keys/msg | wc -c # Should match the Content-Length value

Write a unit test

Use a bytes.Buffer as a fake connection — it implements io.Writer. Wrap it to satisfy net.Conn, then inspect the bytes written:

func TestWriteResponse(t *testing.T) { var buf bytes.Buffer conn := &fakeWriteConn{w: &buf} resp := &server.Response{Status: 200, Body: []byte(`{"ok":true}`)} server.WriteResponse(conn, resp, true) out := buf.String() if !strings.Contains(out, "HTTP/1.1 200 OK") { t.Error("missing status line") } if !strings.Contains(out, "Content-Length: 11") { t.Error("wrong content-length") } if !strings.Contains(out, `{"ok":true}`) { t.Error("missing body") } }
