router.go — Matching Method & Path

The router takes a parsed request and dispatches it to the correct handler. go-go has four routes. The router's job is to match them reliably and return 404/405 for everything else.

The routes

MethodPath patternHandler
GET/keyshandleGetAll
GET/keys/:idhandleGet
PUT/keys/:idhandlePut
DELETE/keys/:idhandleDelete

Path matching — keeping it simple

With only four routes, you don't need a trie or regex. A simple sequence of strings.HasPrefix checks is enough and is easy to reason about:

func (r *Router) Handle(req *Request) *Response { path := req.Path switch { case req.Method == "GET" && path == "/keys": return r.handleGetAll(req) case req.Method == "GET" && strings.HasPrefix(path, "/keys/"): id := strings.TrimPrefix(path, "/keys/") if id == "" { return NotFound() } return r.handleGet(req, id) case req.Method == "PUT" && strings.HasPrefix(path, "/keys/"): id := strings.TrimPrefix(path, "/keys/") if id == "" { return NotFound() } return r.handlePut(req, id) case req.Method == "DELETE" && strings.HasPrefix(path, "/keys/"): id := strings.TrimPrefix(path, "/keys/") if id == "" { return NotFound() } return r.handleDelete(req, id) default: return NotFound() } }

The Response type

type Response struct { Status int Body []byte }

Handlers return a *Response. The response writer in response.go takes that and formats valid HTTP/1.1 headers and body bytes onto the connection.

The handlers themselves

func (r *Router) handleGet(req *Request, id string) *Response { val, ok := r.store.Get(id) if !ok { return &Response{Status: 404, Body: []byte(`{"error":"not found"}`)} } return &Response{Status: 200, Body: val} } func (r *Router) handlePut(req *Request, id string) *Response { if !json.Valid(req.Body) { return &Response{Status: 400, Body: []byte(`{"error":"invalid json"}`)} } r.store.Set(id, json.RawMessage(req.Body)) return &Response{Status: 200, Body: []byte(`{"ok":true}`)} }
json.Valid before storing
json.Valid(req.Body) verifies that the bytes are valid JSON before storing. Without this, a client can store arbitrary bytes and corrupt your cache's JSON invariants. It's a single line that prevents a class of bugs.
